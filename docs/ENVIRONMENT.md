# Environment Variables

| Variable | Purpose |
| --- | --- |
| `APP_ENV` | Runtime environment name. |
| `DATABASE_URL` | SQLAlchemy PostgreSQL URL. |
| `REDIS_URL` | Redis broker/cache URL. |
| `KAFKA_BOOTSTRAP_SERVERS` | Kafka broker list. |
| `JWT_SECRET` | HS256 signing secret. |
| `JWT_ISSUER` | Expected token issuer. |
| `ACCESS_TOKEN_MINUTES` | Access token TTL. |
| `REFRESH_TOKEN_DAYS` | Refresh session TTL. |
| `OPENAI_API_KEY` | AI assistant and OCR/LLM provider key. |
| `FRONTEND_ORIGIN` | CORS origin for the web app. |
